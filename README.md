# 🍽️ Plateforme de Contrôle - Global Food Safety Audit (GFS)

Application développée en Python avec **Streamlit** pour automatiser, suivre et documenter les audits de sécurité sanitaire des aliments (normes GFS / Marriott) au sein de l'hôtel.

## 🚀 Fonctionnalités
- **Contrôles par section :** Documentation, Locaux (Facilities), Manipulation des aliments, Hygiène personnelle.
- **Gestion de la conformité :** Saisie des statuts (Oui / Non / N/A).
- **Observations et actions correctives :** Ajout de commentaires personnalisés pour chaque consigne non conforme.
- **Exportation des rapports :** Téléchargement instantané des résultats sous format **Excel (.xlsx)** ou **CSV**.

## 🛠️ Technologies utilisées
- Python
- Streamlit
- Pandas / Openpyxl
